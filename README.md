# CloudStream 3 Plugin Builder Skill

Autonomous AI pair-programming skill and harness for building, testing, and maintaining CloudStream 3 extensions.

> **Disclaimer: Early-Stage Prototype**  
> This skillset was put together in a rush and is in very early-stage development. It may contain errors, incomplete extraction patterns, or edge-case bugs.  
> Please test carefully, update things as you find issues, and submit pull requests to make it better.

---

## Languages & Tech Stack

* Kotlin (Android SDK API 36, Java 11/17)
* Python 3 (Diagnostic probing, upstream extractor indexing, local hosting)
* Gradle / Kotlin DSL (Plugin build harness)
